ESP32 Marauder Custom

BLE Spam 強化版 Web インストーラー（管理者権限不要）

⚠ このブラウザは WebSerial に未対応です。
Chrome または Edge のデスクトップ版で開いてください。 ⚠ この接続は HTTPS が必要です。

使い方

  1. ESP32 を USB ケーブルで PC に接続
  2. 上の 「ESP32 に書き込む」 ボタンをクリック
  3. シリアルポート（COMxx / /dev/ttyUSBx）を選択
  4. INSTALL を選択 → 完了まで約1〜2分
前提: ESP32 が COM ポートとして認識されていること。
ドライバ（CP210x / CH340）未インストールで認識しない場合は管理者権限が必要です。
Windows 10 / 11 なら多くの場合、標準で認識します。

機能（カスタム内容）

  • BLE 広告 TX パワー 強制最大（+9 dBm） — ADV / SCAN / DEFAULT 全スロット
  • RSSI 偽装で「至近距離デバイス」を装う
  • Kitchen Sink (blespam -t all) 加重ローテーション — Apple×4 / Google×3 / 他×3
  • Apple Action 25 種 / AirPods/Beats 32 種 / FastPair 484 種＋Debug Mode
  • GPIO12 ジャンパで起動時自動 BLE スパム
  • 起動高速化（約120ms 短縮）

ブラウザ要件

  • Chrome 89+ / Edge 89+（デスクトップ版）
  • Firefox / Safari は 非対応（WebSerial 未実装）
  • モバイル版は非対応

上手くいかない場合

  • 書き込み開始後に Connecting...... が続く → ESP32 の BOOT ボタンを押しながら接続してからリトライ
  • ポート選択に出てこない → デバイスマネージャで COM 認識を確認、別ケーブル/別USBポートを試す
  • 書き込み失敗 → ブラウザを閉じて他プロセス（シリアルモニタ等）がポートを占有していないか確認
